# 📊 EduPro Course Demand & Revenue Prediction

## 🔍 Project Overview
This project focuses on predicting course enrollment demand and revenue for an online learning platform (EduPro) using machine learning techniques.

The goal is to help in:
- Data-driven course planning
- Revenue optimization
- Better pricing strategies

---

## 🚀 Features
- Predict course enrollment count
- Forecast course revenue
- Interactive Streamlit dashboard
- Real-time user input predictions

---

## 📂 Dataset
The dataset includes:
- Course details (price, duration, rating, level)
- Instructor details (experience, rating)
- Transaction data (enrollments, revenue)

---

## ⚙️ Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly

---

## 🧠 Machine Learning Models
- Linear Regression (Baseline)
- Random Forest Regressor (Best Performing)

---

## 📊 Evaluation Metrics
- MAE (Mean Absolute Error)
- RMSE (Root Mean Square Error)
- R² Score

---

## 💡 Key Insights
- Course rating strongly influences demand
- Pricing impacts both enrollment and revenue
- Instructor experience improves course performance
