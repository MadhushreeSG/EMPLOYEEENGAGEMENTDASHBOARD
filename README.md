# Employee Engagement and Burnout Analysis Dashboard

## Project Overview
This project analyzes employee engagement and burnout risk using employee data such as job satisfaction, work-life balance, and overtime.

## Features
- Engagement Index Calculation
- Burnout Risk Prediction
- Data Visualization (EDA)
- Machine Learning Models
- Interactive Dashboard using Streamlit

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn (Machine Learning)
- Streamlit

## Objective
To help organizations identify burnout risk and improve employee engagement using data-driven insights.
